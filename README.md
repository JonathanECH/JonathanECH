### 📂 Proyectos Destacados

#### 📊 ContaERP
Una aplicación web diseñada para gestionar los gastos e ingresos de organizaciones. Es una herramienta muy útil pensada para que los contadores puedan agilizar y optimizar sus actividades y cálculos diarios.
*(Desarrollado con Vue 3, Vite y TypeScript)*

#### 🏥 Sistema de Gestión - Clínica Razetti
Un sistema integral de gestión de pacientes que permite registrar, procesar y documentar citas médicas. La plataforma maneja flujos de trabajo completos mediante 4 roles distintos:
- **Paciente:** Registro, agendamiento de citas y revisión de historial médico.
- **Secretario:** Administración de citas diarias y semanales.
- **Médico:** Registro de horarios de disponibilidad y emisión de reportes de consultas.
- **Administrador:** Gestión total del sistema (agregar, modificar y desactivar roles y usuarios).
*(Desarrollado con Angular)*
